## API-Schnipsel

Viele Teams beginnen mit einem schlanken **Node**-Skript, das Sendungen gruppiert:

```js
export function clusterByPostalCode(parcels) {
  const map = new Map()
  for (const p of parcels) {
    const k = p.postalCode.slice(0, 2)
    const list = map.get(k) ?? []
    list.push(p)
    map.set(k, list)
  }
  return map
}
```
