# Willkommen

Diese Website wird mit **PreactPress** erzeugt — einem Static-Site-Generator mit Vite und Preact für Dokumentation, Blogs und Marketing-Seiten.

## Schnellstart

Aus diesem Ordner:

```bash
pnpm install
pnpm run dev
```

Öffne **http://localhost:5173**. Bearbeite Markdown-Dateien, passe `.preactpress/config.ts` an, und der Dev-Server lädt deine Änderungen automatisch neu.
