# Roles and permissions

| Role   | Manage billing | Manage integrations | View audit log |
| ------ | -------------- | ------------------- | -------------- |
| Admin  | yes            | yes                 | yes            |
| Member | no             | no                  | own actions    |
| Viewer | no             | no                  | read-only      |

::: warning Admin only
Only admins can change roles or remove members.
:::
