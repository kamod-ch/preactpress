# API documentation starter (Protocol theme)

Hybrid REST + TypeScript SDK documentation starter styled after a Protocol-like API docs layout.

## Prerequisites

- Node.js 20+
- pnpm (recommended) or npm

## Installation

```bash
pnpm dlx @kamod-ch/preactpress init my-site --template api-docs
cd my-site
pnpm install
```

## Development

```bash
pnpm run dev
```

Open **http://localhost:5173**.

## Production build

```bash
pnpm run build
pnpm run preview
```

## What you get

- **Custom Protocol theme** — dark-first shell with sticky top nav, centered search (Ctrl+K), left sidebar, and mint accent
- **Guides** — Introduction, Quickstart, SDKs, Authentication, Pagination, Errors, Webhooks
- **REST resources** — generated from [`openapi/acme.yaml`](./openapi/acme.yaml) via `@preactpress/plugin-openapi` under `/resources`
- **SDK reference** — MDX pages with `ApiSignature`, `ParameterTable`, `TypeDefinition`, plus REST helpers (`HttpMethodBadge`, `EndpointLine`, `StatusCodeTable`)

## Directory structure

```text
.preactpress/
  config.ts          Site, nav, sidebar, OpenAPI plugin
  theme/             Protocol custom theme (Layout + CSS)
openapi/acme.yaml    Sample OpenAPI 3.1 spec (replace with yours)
components/          Reusable MDX API components
quickstart.md …      Guide pages
functions/           SDK function reference (MDX)
resources/           Generated by the OpenAPI plugin (do not edit)
```

## Swap the OpenAPI spec

Edit `.preactpress/config.ts`:

```ts
openapiPlugin({
  input: "./openapi/your-spec.yaml",
  route: "/resources",
})
```

Then restart `pnpm run dev`. Generated pages land under `resources/`.

## Branding

Edit `site.title`, `site.description`, and `themeConfig.signInLink` in `.preactpress/config.ts`. Colors live in `.preactpress/theme/protocol.css` (`--protocol-*` tokens).

## Deployment

Set `site.url` to your production URL before building. See the [Deploy guide](https://kamod-ch.github.io/preactpress/guide/deploy).

## PreactPress features used

- Custom theme with sidebar, local search, and outline
- Official OpenAPI plugin for REST pages
- Markdown callouts and Shiki code highlighting
- Static sitemap and search index
- Dark / light mode via theme toggle
