# Support

Need help integrating with Protocol?

- Read the [Quickstart](/quickstart) and [Authentication](/authentication) guides
- Browse [REST resources](/resources) generated from the OpenAPI specification
- Email [support@example.com](mailto:support@example.com) for account or billing questions
- Open an issue on the [SDK repository](https://github.com/your-org/your-repo) for client bugs

Status updates are published at [status.example.com](https://status.example.com).
