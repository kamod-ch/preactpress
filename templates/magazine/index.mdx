## Kurz kommentiert

Diese Seite ist eine **Demonstration**: Sie zeigt, wie ein Nachrichten- oder Branchenmagazin mit PreactPress als statische Site aussehen kann — inklusive Teaser-Kacheln als MDX-Komponente und eigenem Layout unter `.preactpress/theme/`.

> Das Layout orientiert sich lose an klassischen Fachmedien (Masthead, Sticky-Navigation, Spalte „In dieser Ausgabe“), ohne eine bestehende Marke nachzubilden.
