# Introducing PreactPress

PreactPress is a static site generator built for teams who want **documentation-first** workflows without adopting React.

## Why Preact?

Preact keeps client bundles small while supporting MDX islands, search, and theme customization. PreactPress ships a default docs theme and starter templates for blogs, API references, SaaS docs, and help centers.

## What you get

- Markdown and MDX with syntax highlighting
- Sidebar navigation, local search, and table of contents
- RSS, sitemap, and Open Graph metadata
- Custom Preact themes when you outgrow the default layout

## Try it today

```bash
pnpm dlx @kamod-ch/preactpress init my-docs --template docs
```
