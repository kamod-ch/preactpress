@preactpress/plugin-playground

Live-Preact-Beispiele direkt in der Doku.

Sandboxed Editor und Vorschau in MDX — ohne CodeSandbox-Tab. Lazy geladen, CDN-Allowlist, Fehler bleiben im Playground. 

import { useState } from 'preact/hooks'
export default function Demo() {
  const [n, setN] = useState(0)
  return <button onClick={() => setN(n+1)}>{n}</button>
}

Ablauf

  1. 1playgroundPlugin() in der PreactPress-Config registrieren.
  2. 2<Playground /> in MDX einbinden.
  3. 3Leser editieren live; Preview läuft im iframe-Sandbox.

FAQ

Brauche ich einen eigenen Preview-Server?

Nein — statisches Sandbox-Dokument plus postMessage.

Beliebige npm-Pakete?

Nur über die konfigurierte CDN-Allowlist; Workspace-Pakete brauchen explizite URLs.

Installation

pnpm add -D @preactpress/plugin-playground

import { playgroundPlugin } from "@preactpress/plugin-playground";
export default defineConfig({ plugins: [playgroundPlugin()] });
