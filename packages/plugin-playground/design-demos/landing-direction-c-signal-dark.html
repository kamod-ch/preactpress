Pipeline

  2. 2Author MDX with live examples.
  3. 3Sandbox iframe executes with import map + debounced runs.

FAQ

What runs inside the iframe?

A static sandbox document built by the plugin; your doc page never evals user code directly.

Can I disable StackBlitz?

Pass stackBlitz={false} on the Playground component.

Read-only mode?

Use readOnly to show code without editing.
