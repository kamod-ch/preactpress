### A · Collins product launch

- **Borrow:** One primary product artifact, generous vertical rhythm, confident sans, single accent from brand sampling (#646cff on neutral slate).
- **Hero material:** CSS-built playground chrome (realistic toolbar + panes).
- **Skeleton:** Centered column, hero mock → three features → install band.
- **Bold spend:** Oversized product frame with subtle perspective shadow.
- **Form from content:** The plugin *is* the UI — show it, don’t describe it with icons.

### B · Dark dev-docs rail

- **Borrow:** Sticky left index, `#0a192f`-class ground, one mint/cyan accent on links, JetBrains Mono for code labels.
- **Hero material:** Same playground mock, dark chrome variant matching `PlaygroundView` dark theme assumption.
- **Skeleton:** 280px sticky nav + main column sections.
- **Bold spend:** Full-width embedded mock with glow edge (not generic gradient blob).
- **Form from content:** Docs readers scan vertically — rail mirrors PreactPress doc IA.

### C · Cinematic sound-viz

- **Borrow:** Full-bleed black, white type, SVG waveform bands, single blue-violet gradient accent.
- **Hero material:** Animated SVG “signal” between code block and preview pane.
- **Skeleton:** Stacked bands — manifesto headline → wave divider → mock → specs row.
- **Bold spend:** Motion on load (CSS only) on waveform bars.
- **Form from content:** “Live” preview = signal path from source to output.

### D · Experimental Jetset (alternate)

- **Borrow:** Strict grid, Helvetica/Inter, uppercase small labels only where functional (file names).
- **Skeleton:** Asymmetric 12-col grid, hero text block left, mock right spanning 7 cols.

### E · Editorial brutalism (alternate)

- **Borrow:** 120px+ headline module, 1px rules, signal orange on one CTA only.
