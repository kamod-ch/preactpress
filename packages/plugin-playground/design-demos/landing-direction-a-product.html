npm package

@preactpress/plugin-playground

Live Preact demos inside your docs.

Drop a sandboxed editor and preview into MDX. Readers tweak hooks and components without leaving the page — lazy-loaded, allowlisted, and isolated in an iframe.

Install in two lines See PreactPress demo
Preact playground 
import { useState } from 'preact/hooks'

export default function Demo() {
  const [n, setN] = useState(0)
  return (
    <button onClick={() => setN(n + 1)}>
      Count: {n}
    </button>
  )
}

Features

Sandboxed preview

Iframe with allow-scripts only — errors stay inside the playground.

Multi-file MDX

Virtual paths, entry file, and versioned dependencies from your allowlist.

Lazy UI

Editor bundle loads only on pages that render <Playground />.

How it fits into PreactPress

  1. 1Add playgroundPlugin() to your PreactPress config.
  2. 2Embed <Playground /> in MDX with inline or multi-file code.
  3. 3Readers edit in the lazy-loaded UI; preview runs in a sandboxed iframe.

FAQ

Does preview run on my docs server?

No separate backend — the iframe loads a static sandbox document and receives code via postMessage.

Can I load arbitrary npm packages?

Only packages from your configured CDN allowlist (Preact ecosystem by default). Workspace packages need explicit URL mapping.

Will a broken example crash my doc page?

Validation errors are shown in the playground UI; the host MDX page keeps rendering.

Setup

pnpm add -D @preactpress/plugin-playground

// .preactpress/config.ts
import { playgroundPlugin } from "@preactpress/plugin-playground";
export default defineConfig({ plugins: [playgroundPlugin()] });
