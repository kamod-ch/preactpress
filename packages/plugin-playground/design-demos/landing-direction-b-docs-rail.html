@preactpress/plugin-playground

Runnable examples for MDX authors.

The playground plugin adds a split editor and live preview to PreactPress docs. Configure once, then embed interactive Preact snippets next to your API reference.

// Live surface

App.tsx 
import { useState } from 'preact/hooks'

export default function Demo() {
  const [n, setN] = useState(0)
  return (
    <button onClick={() => setN(n + 1)}>
      Count: {n}
    </button>
  )
}

// Security model

  • Preview runs in a sandboxed iframe (allow-scripts allow-modals).
  • External packages load from a configurable CDN allowlist.
  • Invalid examples surface errors inside the playground, not the host page.

// FAQ

Lazy loading?

Playground UI code loads only when MDX renders <Playground />.

Workspace packages?

Map them explicitly in createPlaygroundComponents({ workspacePackages }).

// Install

pnpm add -D @preactpress/plugin-playground

import { playgroundPlugin } from "@preactpress/plugin-playground";

export default defineConfig({
  plugins: [playgroundPlugin()],
});
